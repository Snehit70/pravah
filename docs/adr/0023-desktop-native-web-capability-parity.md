# Web capability parity uses desktop-native ergonomics

Status: accepted

Pravah web will catch up to mobile by providing the same planning capabilities while using a desktop-native information architecture and interaction model. Web may retain persistent side panels, keyboard shortcuts, hover affordances, and wider analytical layouts; visual or gesture-level duplication of mobile is not a requirement. This preserves the product's single planning model without turning the desktop client into an oversized phone UI.
